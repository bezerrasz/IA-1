<|user|> o que é um modelo de linguagem?
<|assistant|> um modelo de linguagem aprende padrões em textos para prever o próximo token de uma sequência. <|endoftext|>

<|user|> o que é uma llm?
<|assistant|> uma llm é um modelo de linguagem de grande porte. este projeto usa uma versão pequena para estudar seus componentes. <|endoftext|>

<|user|> o que significa gpt?
<|assistant|> gpt significa transformer generativo pré-treinado. a arquitetura prevê tokens usando o contexto disponível. <|endoftext|>

<|user|> o que é um token?
<|assistant|> um token é uma unidade de texto. pode representar uma palavra, uma parte de palavra ou um sinal de pontuação. <|endoftext|>

<|user|> para que serve o tokenizador?
<|assistant|> o tokenizador divide o texto em unidades e transforma essas unidades em identificadores numéricos. <|endoftext|>

<|user|> o que é um vocabulário?
<|assistant|> o vocabulário associa cada token conhecido a um identificador. essa associação precisa ser preservada junto com os pesos do modelo. <|endoftext|>

<|user|> por que aparece um token desconhecido?
<|assistant|> o token desconhecido aparece quando uma palavra não está no vocabulário criado com os dados de treinamento. <|endoftext|>

<|user|> o que são embeddings?
<|assistant|> embeddings são vetores numéricos aprendidos que representam tokens. eles permitem que a rede processe o texto com operações matemáticas. <|endoftext|>

<|user|> para que servem os embeddings posicionais?
<|assistant|> os embeddings posicionais informam a posição de cada token. a ordem das palavras é importante para interpretar uma frase. <|endoftext|>

<|user|> o que é atenção?
<|assistant|> a atenção combina informações de diferentes posições do contexto para produzir uma representação de cada token. <|endoftext|>

<|user|> para que serve a máscara causal?
<|assistant|> a máscara causal impede que uma posição consulte tokens futuros. assim o modelo aprende a prever usando apenas o contexto permitido. <|endoftext|>

<|user|> o que é atenção com várias cabeças?
<|assistant|> a atenção com várias cabeças divide a representação em partes e calcula relações em diferentes espaços. depois reúne os resultados. <|endoftext|>

<|user|> o que é um transformer block?
<|assistant|> um transformer block reúne atenção, normalização, rede feedforward e conexões residuais. sua saída mantém a dimensão da entrada. <|endoftext|>

<|user|> qual é a função da normalização?
<|assistant|> a normalização ajuda a controlar a escala das ativações. isso contribui para a estabilidade do processamento e do treinamento. <|endoftext|>

<|user|> para que serve a conexão residual?
<|assistant|> a conexão residual soma a entrada ao resultado de uma transformação. ela ajuda a preservar informações e facilita o fluxo dos gradientes. <|endoftext|>

<|user|> o que é uma rede feedforward?
<|assistant|> a rede feedforward aplica transformações não lineares a cada posição. ela aumenta a capacidade de representação do bloco. <|endoftext|>

<|user|> o que é gelu?
<|assistant|> gelu é uma função de ativação usada na rede feedforward. ela introduz uma transformação não linear suave. <|endoftext|>

<|user|> o que é dropout?
<|assistant|> dropout desativa parte das ativações durante o treinamento. na avaliação, ele fica desativado para permitir previsões estáveis. <|endoftext|>

<|user|> o que são logits?
<|assistant|> logits são os escores produzidos pelo modelo para cada token do vocabulário. a função softmax pode transformar esses escores em probabilidades. <|endoftext|>

<|user|> o que faz a camada de saída?
<|assistant|> a camada de saída transforma os vetores finais em escores para todos os tokens do vocabulário. <|endoftext|>

<|user|> como o modelo gera uma frase?
<|assistant|> o modelo prevê um token, acrescenta esse token ao contexto e repete o processo até atingir o limite ou gerar o marcador de fim. <|endoftext|>

<|user|> o que é geração autorregressiva?
<|assistant|> é a geração em que cada token novo depende do contexto formado pelos tokens anteriores. <|endoftext|>

<|user|> para que serve a temperatura?
<|assistant|> a temperatura controla a concentração das probabilidades na amostragem. ela pode mudar a variedade do texto gerado. <|endoftext|>

<|user|> o que faz o top-k?
<|assistant|> o top-k limita a amostragem aos tokens com maiores escores. isso reduz a escolha de opções muito improváveis. <|endoftext|>

<|user|> o que é seleção greedy?
<|assistant|> a seleção greedy escolhe o token com maior escore a cada passo. ela pode produzir respostas repetitivas. <|endoftext|>

<|user|> como funciona o treinamento?
<|assistant|> o treinamento compara previsões com os tokens corretos, calcula o erro e ajusta os pesos para reduzir esse erro. <|endoftext|>

<|user|> o que é uma época?
<|assistant|> uma época corresponde a uma passagem pelas amostras do conjunto de treinamento. <|endoftext|>

<|user|> o que é um lote?
<|assistant|> um lote reúne várias amostras para processamento conjunto. o tamanho do lote influencia o uso de memória. <|endoftext|>

<|user|> para que serve o dataset?
<|assistant|> o dataset organiza as sequências de entrada e seus alvos. o alvo de cada posição é o próximo token. <|endoftext|>

<|user|> para que serve o dataloader?

<|user|> o que é uma função de perda?

<|user|> o que é cross-entropy?

<|user|> o que são gradientes?
